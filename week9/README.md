# Week 9 — Atomic Red Team: run the emulation plan and score it in a SIEM (Assignment 6, part 1)

Project: **Detecting Spearphishing Attacks in Corporate Networks** · Danial Rahman · CS-2421 · Introduction to Threat Hunting.

Syllabus 2026–2027, §3.3 Week 9 task: run selected Atomic tests (e.g. T1059, T1003) and record and analyse the results in a SIEM. We run the 9 Atomic tests from the Week 8 plan, pinned by GUID at atomic-red-team commit `a0e3f9bc69`. We convert 3 Week 7 and 9 new Sigma rules to Splunk SPL and SQLite with pySigma, execute them, and score every test as detected, partial or missed.

> Telemetry is **synthetic**: it is generated from each test's real command line and Invoke-AtomicRedTeam's wrapping, plus a benign baseline. The runbook is ready for the lab VM. After a real run, replace `data/atomic_run_telemetry.ndjson` and `data/run_log.csv` with the Splunk export and the runbook's log, then re-run the scripts.

## Layout

```
week9/
├── atomics/selected_tests.json         pinned Atomic tests (name, GUID, executor, command, cleanup)
├── runbook/Invoke-Week9Atomics.ps1     lab runbook (LAB-WIN10-01 only), writes run_log.csv
├── rules/                              w7_* (Week 7 CAR rules, unchanged) + w9_* (new)
├── queries/*.spl, *.sql                generated by convert_rules.py
├── data/{atomic_run_telemetry.ndjson, run_log.csv}
├── scripts/
│   ├── fetch_atomics.py                Week 8 plan -> pinned Atomic YAML -> atomics/selected_tests.json
│   ├── generate_telemetry.py           Sysmon-schema telemetry for each test + baseline
│   ├── convert_rules.py                Sigma -> SPL + SQLite (Sysmon pipeline on both)
│   ├── run_siem.py                     load SQLite, execute, attribute by run window, score
│   └── make_figures.py
├── images/{detection_matrix.png, coverage_before_after.png}
├── attack/navigator_layer.json
└── docs/{week9_report.md, detection_matrix.md, test_results.json, execution_output.txt, conversion.json}
```

## Reproduce

```bash
cd week9
python3 -m pip install pyyaml matplotlib pysigma pysigma-backend-splunk pysigma-backend-sqlite pysigma-pipeline-sysmon
python3 scripts/generate_telemetry.py && python3 scripts/convert_rules.py && python3 scripts/run_siem.py && python3 scripts/make_figures.py
```
