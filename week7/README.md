# Week 7 — Using MITRE CAR: analytics implemented and executed in a SIEM

Project: **Detecting Spearphishing Attacks in Corporate Networks** · Danial Rahman · CS-2421 · Introduction to Threat Hunting.

Syllabus 2026–2027, §3.3 Week 7 task: select an analytic from MITRE CAR, implement it in a SIEM, and map it to ATT&CK. We implement **CAR-2014-04-003** (raw + tuned) and **CAR-2013-02-003** as Sigma rules, convert them to **Splunk SPL and SQLite** with pySigma, **execute** the SQLite form against a log store, and map coverage to **ATT&CK v20**. Synthetic data; nothing is executed on a host or network.

## Pipeline

```
MITRE CAR analytic -> Sigma rule (rules/*.yml) -> pySigma -> SPL (queries/*.spl) + SQLite (queries/*.sql) -> run_hunt.py -> results
```

## Reproduce

```bash
cd week7
python3 -m pip install "pysigma>=1.5,<2" "pysigma-backend-splunk>=1.1,<2" \
    "pysigma-backend-sqlite>=2.1,<3" "pysigma-pipeline-sysmon>=1,<2" "pysigma-pipeline-windows>=1,<2"
python3 scripts/convert_rules.py     # rules -> queries/*
python3 scripts/run_hunt.py          # execute SQLite queries -> docs/*
python3 scripts/make_figures.py      # -> images/*, attack/navigator_layer.json
```
`run_hunt.py` alone needs no third-party packages (stdlib `sqlite3`), so the executed results reproduce even without pySigma installed; `convert_rules.py` needs pySigma to regenerate the queries.
